논문 「Connectome Mapping: Shape-Memory Network via Interpretation of Contextual Semantic Information」가 ICLR 2025에 채택되었습니다! 4월 싱가포르에서 연구 성과를 발표할 예정입니다.

#### 초록

맥락적 의미 정보는 뇌가 주변 환경을 시각적으로 해석하는 데 핵심적인 역할을 합니다. 시각 정보를 처리할 때 시냅스 내 전기 신호는 서로 다른 객체와 관련된 맥락적 의미 정보에 따라 시냅스 연결의 동적 활성화와 비활성화를 유도합니다. 인공지능 분야의 신경망은 이러한 복잡한 신호 전달 체계를 모사하는 강력한 도구로 발전하여, 시각 정보를 이해하고 분류 및 분할 등의 작업을 수행합니다. 그러나 기존 신경망은 뇌의 전체 신경 연결 지도를 뜻하는 커넥톰의 조건부 활성화와 비활성화를 모사하는 데 한계가 있습니다. 또한 기존 신경망의 픽셀 단위 추론은 예측 과정에서 맥락적 의미 정보를 명시적으로 활용하지 못했습니다. 이를 해결하기 위해 Shape Memory Network(SMN)라는 새로운 신경망을 개발했습니다. SMN은 (1) 뇌 커넥톰의 복잡한 작동 원리를 충실히 모사하고, (2) 추론 과정에서 맥락적 의미 정보를 명시적으로 반영합니다. SMN은 맥락적 의미 정보에 적합한 구조를 기억하고 추론 시 활용합니다. 이러한 구조 변환은 커넥톰 내 시냅스 연결의 조건부 활성화와 비활성화를 모사합니다. 다양한 의미론적 분할 벤치마크에서 엄밀한 실험을 수행하여 SMN의 우수성과 효과를 확인했습니다. 커넥톰 모사에 관한 이 연구는 차세대 신경망을 위한 SMN의 큰 잠재력을 보여줍니다.
